# 📖 What is Recursion?

Recursion is a programming technique in which a function calls itself to solve a smaller instance of the same problem until it reaches a **base case**.

Every recursive solution has:

- Base Case
- Recursive Call

---

# 🔹 Recursion Flow

```text
Function(n)

↓
Base Case ?
    Yes → Stop
    No  → Solve smaller problem
             ↓
       Function(n-1)
```
