# 📖 What is Backtracking?

Backtracking is an algorithmic technique that builds a solution step by step. If a choice does not lead to a valid solution, it **undoes (backtracks)** that choice and tries another possibility.

It follows the pattern:

1. Choose
2. Explore
3. Backtrack (Undo the choice)
