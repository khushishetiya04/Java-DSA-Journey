# 📖 Concepts Covered

- Every value in the left subtree is smaller than the root.
- Every value in the right subtree is greater than the root.
- Inorder traversal of a valid BST gives values in sorted order.
- BST allows efficient searching, insertion, and deletion.
- BST property can be used to eliminate half of the tree during search.
- BST can be constructed from a sorted array to create a balanced tree.

# 🔹 Time Complexity

| Problem                            | Time | Space 
| -----------------------------------|------|------- 
| Search in a BST                    | O(h) | O(h) 
| Insert into a BST                  | O(h) | O(h) 
| Minimum Absolute Difference in BST | O(n) | O(h) 
| Range Sum of BST                   | O(n) | O(h) 
| Validate BST                       | O(n) | O(h) 
| LCA of BST                         | O(h) | O(h) 
| Delete Node in BST                 | O(h) | O(h) 
| Convert Sorted Array to BST        | O(n) | O(h) 

> `h` = height of the BST.  
> For a balanced BST, `h = O(log n)`.  
> In the worst case, a skewed BST can have `h = O(n)`.
